How It Works

1. Define your reservoir wells and rates

2. Train the PINN baseline model (~30s)

3. Run what-if scenarios by changing well rates

4. Compare results in seconds


Each scenario trains a physics-informed neural network from scratch — 1000× faster than conventional FDM simulators.


Reservoir: 2-phase black-oil • SPE-1 PVT • Peaceman wells

Model: 3×64 trunk + 2×64 branches • tanh • Adam • IDW constraints

Parameters: ~17K • zero external deps • C++20 static binary
